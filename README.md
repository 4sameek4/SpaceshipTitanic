# 🚀 Spaceship Titanic
Dataset used is : **https://www.kaggle.com/competitions/spaceship-titanic**
## 📌 Project Overview

This project was developed as part of the Kaggle – Spaceship Titanic competition. The goal is to predict passenger survival outcomes using structured tabular data. The project emphasizes both team collaboration and model comparison, led under a structured project management approach.

I served as Project Manager, leading a team of four in designing, implementing, and evaluating multiple machine learning models, as well as developing a supporting website to present results and insights.

## 👥 Team & Leadership

Role: Project Manager

Team Size: 4 members

Coordinated task allocation, timeline planning, and integration of modeling and web development components

Ensured reproducibility, model evaluation consistency, and clear result reporting

## 🤖 Models Implemented

Two machine learning models were implemented and compared to evaluate predictive performance:

**🔹 Logistic Regression**

Accuracy: 62.22%

F1 Score: 0.6156

AUC-ROC: 0.6748

**🔹 CatBoost Classifier**

Accuracy: 79.79%

F1 Score: 0.7914

AUC-ROC: 0.8611

CatBoost significantly outperformed Logistic Regression, demonstrating the effectiveness of gradient boosting methods on structured tabular data.
